# Mardochée BONOU

- Programme : Networkwalks Cybersecurity Internship.
- Batch : **B084**.
- Projet : Mediroza, semaine 4, jalons M1 à M4.
- Profil GitHub : [Mardoch45](https://github.com/Mardoch45).

Ce projet présente mon travail de reconnaissance, de compréhension des protections de PDF, d'analyse de données SQL et de rédaction d'un rapport de pentest. Le bilan personnel du rapport décrit les compétences travaillées et peut être adapté à mon expérience.

La version publique présente la méthode et un jeu de données fictif. Les annexes confidentielles du projet sont conservées dans le livrable destiné à l'instructeur.
